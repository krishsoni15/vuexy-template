## ⚡ Quick Start

### 1. View Locally (Zero Setup)
Open `index.html` directly in your browser, or run a local server:

```bash
# Node.js
npx serve . -p 3000

# Python
python3 -m http.server 3000
```
Open **`http://localhost:3000`** to launch the **Master Portal & Explorer**.

### 2. Deploy to Vercel (1-Click)
1. Import this repository on **[vercel.com/new](https://vercel.com/new)**.
2. Select **Other** as the framework preset and click **Deploy**.
3. All static asset routes are automatically handled by `vercel.json`.
