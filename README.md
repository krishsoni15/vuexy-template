# Vuexy Admin Template (Free Offline Mirror)

[![Scraped with WebHarvest](https://img.shields.io/badge/scraped%20with-WebHarvest-28c76f?style=flat-square)](https://webharvest.onrender.com/)
[![145+ Pages](https://img.shields.io/badge/pages-145%2B%20HTML-7367f0?style=flat-square)](./index.html)

A free, offline-ready mirror of the **Vuexy Admin Dashboard Template**, scraped using **[WebHarvest](https://webharvest.onrender.com/)**.

All 145+ pages, styles, scripts, fonts, and images are bundled locally so you can use and browse everything completely offline.

---

## 📁 What's Inside

- **`index.html`** — Master page with search & filters to browse all 145+ templates.
- **`html/vertical-menu-template/`** — 145+ HTML pages (CRM, eCommerce, Logistics, Academy, Apps, UI components, etc.).
- **`login/`** — Standalone Bootstrap 5 auth pages (login, register, forgot password).
- **`nextjs-login/`** — Next.js React login screens.
- **`assets/`** — All local CSS, JS, Tabler icons, and illustrations.

---

## 🚀 How to Run

### Open Locally
Double-click **`index.html`** to open it in your browser, or run a quick local server:

```bash
npx serve . -p 3000
# or
python3 -m http.server 3000
```
Then visit `http://localhost:3000`.

### Deploy to Vercel
You can deploy this repo straight to [Vercel](https://vercel.com) with 1 click. `vercel.json` is already configured for all asset routes.
